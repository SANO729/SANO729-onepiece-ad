# One Piece AD — Lote 1 (MVP)

Este repositório contém os arquivos iniciais (Lote 1) do addon "One Piece AD".

Conteúdo incluído neste commit:
- behavior_pack/ (manifests, items, eventos, component_groups, skills, scripts experimentais protótipo)
- resource_pack/ (manifest apenas; texturas devem ser adicionadas em resource_pack/textures/items/)
- tools/build-mcpack.sh — script para gerar um .zip que pode ser renomeado para .mcpack
- README com instruções de instalação

Como testar rapidamente:
1. Baixe o repositório (pelo GitHub: Code -> Download ZIP) ou clone.
2. Preencha texturas em resource_pack/textures/items/ (ex.: fruit_gomu.png) ou use placeholders.
3. Rode tools/build-mcpack.sh para gerar OnePieceAD_Lote1.zip e renomeie para OnePieceAD_Lote1.mcpack.
4. Abra o .mcpack no seu dispositivo com Minecraft Bedrock 1.26.x; ative Resource e Behavior Packs no mundo e (se usar scripts) habilite Experimental Gameplay.

Aviso legal: Este projeto é um fan-project. Use o nome "One Piece AD" apenas em contextos não comerciais para reduzir riscos de violação de IP.
